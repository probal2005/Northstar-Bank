# 📖 Overview

Northstar Bank is a **modern digital banking website** developed using **HTML, CSS and JavaScript**.

It features an elegant banking interface inspired by premium fintech applications, including animated dashboards, responsive layouts, secure banking interactions, beautiful transitions, and an interactive customer portal.
